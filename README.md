# Retail — restyle ONE PSIM

Источник стиля: соседний клон `../ONE.PSIM.PrototypeKit` (`AGENTS.md`, `docs/RESTYLE-RULES.md` §0–§4). Словарь и native-лестницы скопированы из кита как есть, без пересборки.

Изменено только оформление. Разметка — две строки подключения `bridge.css` и `data-theme="dark"` на полном прототипе (китовский Dark живёт на `[data-theme=dark]`, не на `:root`). JS и адаптив не трогались.

Скриншоты и `npm run build` / `npm run check` **не делались** — отдельный шаг по запросу владельца.

| Файл | Роль |
|---|---|
| [`theme/one-psim.css`](theme/one-psim.css) | Словарь `--one-*` из кита |
| [`theme/native.css`](theme/native.css) | Чекбокс / радио / switch / `<select>` без классов (D-040) |

## Диагностика (§0)

- Слой переменных есть в обоих HTML: полный — только `:root` (тёмная тема); короткий — `:root` + `[data-theme=light|dark]`.
- Hex много, в т.ч. вне переменных (видео-заглушки, ранги, `<mark>`, часть тегов). Видимые статусы и категории перекрыты в `bridge.css`; HUD камеры, силуэты, подсветка титров оставлены (§2.11).
- `--border` в потреблении и рамка контрола, и граница региона. Контролы получают лестницу editor явно; регионы — `--border` (= `surface-subtle` в Light, `--one-border` в Dark, D-024).
- `--accent-hover` в прототипе был *темнее* rest; в DS primary-hover *светлее* rest. Маппинг на `--one-primary-hover`.
- Состояния с цветом: `.active` (nav, mode, filter-chip, tab, split-tab, result/alert/scenario), `.selected` (receipt-row), `:hover`, `:focus` / `:focus-visible`. `aria-pressed` нет. Чекбоксов и радио в разметке нет.

## Что сделано

Переменные обоих прототипов сведены на `--one-*` по таблице §1. Поверх — правила, которые переменные не выражают:

- primary / outline (ghost) / ToggleButton (`mode-btn`, `filter-chip`) — дословно §2.8;
- боковая навигация и вкладки `.tab` / `.split-tab` — `nav-selected` (D-031), не заливка primary;
- кнопка темы — subtle, не ToggleButton и не жёлтая «солнечная» заливка;
- `.btn-danger` — палитра red (у Button нет danger appearance, D-012); подпись не меняет цвет;
- поля: rest / hover / focus-halo 2px, не outline-кольцо (§2.6);
- рамки контролов 1px (§2.5);
- выбранная строка чека / результата / тревоги — `accent-soft`, подпись `fg` (§2.3);
- заголовки панелей `heading-sm` (§2.2b);
- приоритеты — тройки danger / warning / info;
- источники и зоны (касса, 1С, ФР, КСО, ОФД, весы, видео, зал) — `--one-palette-*` по рецепту §2.2a, без green/red рядом со статусами (D-039);
- `native.css` подключён; для `select` восстановлены `appearance: none` и стрелка (прототип пишет `background:` целиком). Страховочная строка `appearance: none` на checkbox/radio — чекбоксов в UI нет.

Оба варианта открываются с одним `bridge.css`.

## Решения, которые принял сам

1. **Полный прототип по умолчанию Dark.** У него не было переключателя темы; кит кладёт Light на `:root`. Повесил `data-theme="dark"` на `<html>`, иначе полный UI стал бы светлым.
2. **Фильтр-чипы `.filter-chip.active`** трактовал как ToggleButton (§2.4), не как чип из пробела §2.12: это сегменты «Все / Кассы / КСО», как Архив/Online в IM.
3. **Радиусы панелей** свёл к `--one-radius-window` / `--one-radius-container`. Геометрию плотности не трогал (D-004).
4. **Подпись логотипа** (`.logo span`) — `--one-fg-subtle`, не accent: иначе единственный «кричащий» синий в шапке.
5. **Hex видео-макета** (камера, силуэты, `<mark>` в титрах, медали рейтинга) не выносил в переменные — это заглушка кадра, не хром DS.

## Пробелы правил (§2.12) — лестницу не выдумывал

| Контрол | Что есть сейчас | Почему не трогал |
|---|---|---|
| Чипы `.chip` без приоритета | фон `surface-muted` | Нет лестницы chip |
| `.btn-danger` | палитра red как у D-012 | У Button нет danger appearance — записал как палитру, не как выдуманную лестницу Button |
| Точки/тики камеры, счётчик 5:1 | как в прототипе | Нет лестницы pager-dots |
| `focus-within` у групп полей | нет обёртки | Пробел §2.12 |
| Две ссылки «Возвраты / КСО с тревогами» в `index.html` | inline `color:#93c5fd` | Без правки разметки stylesheet не перебивает inline; правило Link §2.14 на них не действует |

Чекбокс / радио / switch в этих экранах не встречаются — `native.css` подключён заранее.

## На подтверждение владельцу

- Полный прототип остаётся без переключателя темы: только Dark. Добавить солнышко как в short — отдельное UX-решение.
- Фильтр-чипы на лестнице primary: если владелец считает их чипами, а не сегментами — вернуть нейтральный selected и ждать лестницу chip.
- Радиусы ONE вместо 8–10px прототипа — оставить или откатить двумя строками в `bridge.css`.
- Категории источников: teal / purple / magenta / orange. Другой набор палитры — свобода прототипа (D-016).
- Скриншоты light/dark 1440×900 и `npm run check` — следующий шаг.
